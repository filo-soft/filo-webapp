# ФИЛОСОФТ — Telegram Mini App (баннер)

Главный экран мини-приложения Telegram: **один новостной баннер**, который
меняется на лету без кода. Данные баннера — в `config.json`.

## Что внутри

```
filo-webapp\
  ├── index.html        страница мини-аппа
  ├── styles.css        фирменный стиль ФИЛОСОФТ (цвета, шрифт Mabry Pro)
  ├── app.js            рендер баннера из config.json + Telegram WebApp API
  ├── config.json       ← ЕДИНСТВЕННОЕ место, где ты правишь баннер
  └── assets\
       ├── fonts\       шрифт Mabry Pro (Regular/Medium/Bold/Black)
       ├── logo-h-white.svg     логотип горизонтальный (белый)
       └── mark-white.svg       знак </>  (белый)
```

## КАК МЕНЯТЬ БАННЕР (без кода и установки)

1. Открой файл **`config.json`** на GitHub (веб-интерфейс).
2. Нажми **✏️ Edit** (карандаш) в правом верхнем углу.
3. Измени нужные поля:
   - `title` — заголовок события (большой текст баннера)
   - `text` — описание/детали
   - `date` — дата (любая строка)
   - `tag` — маленькая надпись-ярлык сверху («Событие», «Новость»...) *— чтобы включить, добавь строку `"tag": "..."`*
   - `link.label` — текст кнопки («Подробнее»...)
   - `link.url` — ссылка, куда ведёт кнопка
   - `active` — `true` (показывать) или `false` (скрыть баннер)
4. Нажми **Commit changes** (сохранить).
5. Готово — изменения появятся в боте автоматически (обнови мини-апп свайпом).

Чтобы **убрать баннер совсем**: поставь `"active": false`. Чтобы **вернуть**: `true`.

## Поля config.json

```jsonc
{
  "banner": {
    "active": true,           // true = показывать, false = скрыть
    "tag": "Событие",         // маленький ярлык сверху (необязательно)
    "title": "Заголовок события",
    "text": "Описание. Что произошло и почему это важно.",
    "date": "2026-10-14",
    "link": { "label": "Подробнее", "url": "https://..." }
  },
  "app": {
    "footerText": "ФИЛОСОФТ — цифровая экосистема для недвижимости"  // подпись внизу
  }
}
```

## Публикация на GitHub Pages (дать доступ боту)

1. Заведи репозиторий на GitHub (например, `filo-webapp`, на аккаунте `filo-soft`).
2. Залей в него **содержимое этой папки** (index.html, styles.css, app.js,
   config.json, папку assets).
3. В репозитории: **Settings → Pages** → Source = **Deploy from a branch** →
   выбрай ветку `main`, папку `/ (root)` → **Save**.
4. Через 1–2 мин получишь адрес вида:
   `https://filo-soft.github.io/filo-webapp/`
5. Открой этот URL в браузере — увидишь баннер (работает и как обычный сайт).

## Подключить бота (создать Mini App в Telegram)

1. В Telegram найди **BotFather** → `/newbot` → создай бота.
2. `/mybots` → твой бот → **Bot Settings** → **Menu Button** → задай URL
   мини-аппа: `https://filo-soft.github.io/filo-webapp/`.
3. Можно добавить кнопку в **Bot Settings → Menu / WebApp**.
4. Готово: в боте появится кнопка, открывающая баннер внутри Telegram.

## Заметки

- Статика + `config.json` = самому менять баннер без кода и передеплоя.
- Мини-апп подхватывает тему Telegram (тёмная/светлая) через Telegram WebApp API.
- Все углы резкие, палитра и шрифт — по фирменному стилю ФИЛОСОФТ.
